# Flip the Frame: Photo Selects

Candidate photos for Deborah D. Douglas's chapter in *Journalism Education, Reimagined*.

## Publish with GitHub Pages
1. Create a new repository and upload **everything in this folder** (keep the `images/` folder structure).
2. Go to **Settings → Pages**, set Source to **Deploy from a branch**, choose `main` and `/ (root)`, then **Save**.
3. Your page will appear at `https://<your-username>.github.io/<repo-name>/` within a minute or two.

## Files
- `index.html`: the gallery page
- `images/web/`: smaller previews shown on the page
- `images/full/`: full-resolution originals (what the Download buttons deliver)
- `flip-the-frame-photos.zip`: all originals in one download
